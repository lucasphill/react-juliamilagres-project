# Julia Milagres — Psicologia clínica

Landing page em uma página, mobile first, com azul petróleo, logos próprias em
`src/assets`, superfícies de vidro fosco e movimento reduzido acessível.

React + TypeScript + Vite. React Router para a rota /; Ant Design como fonte de
componentes; Tailwind para composição. Conteúdo local, sem formulários clínicos ou backend.

## Desenvolvimento

`npm ci` e `npm run dev`. Node 24 LTS utilizado no desenvolvimento.

Os comandos de pré-renderização, publicação e testes estão sendo implementados conforme
[plano](specs/001-psychology-landing-page/plan.md).
Conteúdo profissional, contato e domínio precisam de aprovação antes de publicação.
